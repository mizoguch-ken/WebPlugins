plug-ins, which are both written for the WebViewer project : no library of an other project is
shaded in the jar, and the transformer uses no native library.

java language holds : no library of an other project is needed for that.

gson is not shaded either : the WebViewer which loads the plug-in holds gson, and shows its
licenses with its own plug-ins.
